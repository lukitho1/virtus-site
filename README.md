# Site Virtus · virtusbiohacking.com

Publicado pelo GitHub Pages a partir da branch `main`. Cada alteração enviada aqui vai ao ar em 1 a 2 minutos.

## Onde mexer
- `dados/precos.js`: preços do catálogo (uma linha por produto).
- `dados/estoque.js`: selos "Esgotado" e "Últimas unidades".
- `dados/black.js`: preços da Black Week (entram e saem sozinhos nas datas).
- `dados/metricas.js`: código do site no Umami (métricas).
- `index.html`: catálogo, fichas, calculadora, artigos e Black.
- `protocolos/`: biblioteca de protocolos.

## Regras da equipe
- Sempre baixe a versão mais recente antes de editar (`git pull`).
- Não apague os blocos marcados com `TEMA BLACK` (eles se desligam sozinhos em 27/11 às 23h59).
